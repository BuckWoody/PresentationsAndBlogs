# The Team Data Science Process

A presentation and handout introducing the Team Data Science Process (TDSP), a lifecycle for running data science projects as a team.

## Contents

- [Data Science - The Team Data Science Process.pptx](Data%20Science%20-%20The%20Team%20Data%20Science%20Process.pptx) - 21 slides: session objectives, the data science difference, data acquisition, storage and processing, and the project formula (Question + Data + Analysis = Answer).
- [tdsp_handout.docx](tdsp_handout.docx) - the handout that goes with the slides, with links to the Microsoft TDSP documentation.

Older material. The deck was last saved in November 2017. Check Microsoft's current documentation for updated TDSP guidance.
