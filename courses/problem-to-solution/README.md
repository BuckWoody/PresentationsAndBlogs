# Using a Database to Find Solutions for Business Problems

A hands-on session (originally a Microsoft presentation from the SQL Server team) that uses a database of business problems and solutions.

## Contents

- [01-IntroAndSetup.ipynb](01-IntroAndSetup.ipynb) - introduction and setup.
- [02-QueryProblemsAndSolutionsDB.ipynb](02-QueryProblemsAndSolutionsDB.ipynb) - querying the database.
- [solutions_database_script.sql](solutions-database-script.sql) - script that creates the Problems and Solutions database.
- `solutions.bak` - a SQL Server backup of the same database.
- [SQLToAzure.pbix](SQLToAzure.pbix) - Power BI report.
- [Solutions.vsdx](Solutions.vsdx) and [Stencil - Azure.vss](stencil-azure.vss) - Visio diagram and Azure stencil.
- [graphics/erd.png](graphics/erd.png) - entity relationship diagram.
