# Generative AI: Prompting

Notes and a small tool for writing better prompts for large language models.

## Contents

- [prompting.md](prompting.md) - the prompt format I use, and the CREATE model (Character, Request, Examples, Adjustments, Type of output).
- [promptbuilder.html](promptbuilder.html) - a single-page web tool that assembles a prompt from that format. Open it in a browser; it loads Tailwind CSS and a font from the internet.
