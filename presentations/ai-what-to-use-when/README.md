# AI: What to Use When

Presentations on choosing among Azure AI solutions, plus a sample data science engagement kit.

## Contents

- [bwoody - What to Use When.pptx](bwoody-what-to-use-when.pptx) - 36 slides, "Introduction to Azure AI Solutions and Technologies: What to Use When."
- [project-assets/ml-ai-dl-for-the-data-professional.pptx](project-assets/ml-ai-dl-for-the-data-professional.pptx) - 25 slides on machine learning, AI, and deep learning.
- [project-assets/](project-assets/) - a worked example engagement ("Contoso Secure Manufacturing") that follows the project lifecycle: discovery, envisioning, decision tree, proof of concept, implementation, handoff, charter, data dictionary, project plan, and closeout. Includes Word, PowerPoint, Excel, Visio, and Project files.

## Status

Older material from 2018 to 2019. Azure service names and features may have changed since then.
