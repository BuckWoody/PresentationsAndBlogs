# SQL Server 2019 Big Data Clusters Workshop

An architecture workshop on SQL Server 2019 Big Data Clusters (BDC), plus a fraud-detection example notebook.

## Contents

- [SQL Server 2019 Big Data Clusters Workshop.pptx](sql-server-2019-big-data-clusters-workshop.pptx) - 47 slides, organized in modules starting with the big data landscape.
- [Fraud.ipynb](Fraud.ipynb) - credit card fraud detection notebook (data source and references are listed in the notebook).

## Status

Archived. Microsoft retired SQL Server 2019 Big Data Clusters and ended support on February 28, 2025 (see the [Microsoft Learn overview](https://learn.microsoft.com/en-us/sql/big-data-cluster/big-data-cluster-overview)). This material is kept for reference only.
