# Workshop: Claude for Technical Consultants

## Security Policy

This repository contains training materials only,  markdown documents and fictitious sample data (the "Contoso Retail" scenario). It contains no application code, no credentials, and no real customer data.

## Reporting a concern

If you find something in this repository that shouldn't be here,  for example, real customer data that was mistakenly committed, or a broken/misleading claim about a security-relevant topic in Module 06,  please report it to whoever your organization has designated as the owner of this repository, rather than opening a public issue, until it's been reviewed.

## Scope note

Module 06 of this workshop discusses Anthropic's published data-handling and security policies as a *teaching example*. This document, and Module 06 itself, are not a substitute for your own organization's security review of any AI tool, and should not be cited as an authoritative security assessment of Claude or any other product. Direct any real security-assessment questions to your organization's security team and to [Anthropic's Trust Center](https://trust.anthropic.com) directly.
