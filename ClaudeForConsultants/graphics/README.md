# graphics/

The `sqlworkshops-template` repo this course's layout is based on decorates its README with small section icons hotlinked from Microsoft's own CDN. This repo intentionally leaves that folder empty rather than hotlinking those specific images: they're Microsoft's assets for Microsoft's own SQL Server workshop family, and this is a Claude-focused course for a general technical-consulting audience, not a Microsoft-branded workshop.

If you'd like the same decorative-icon convention you've used on your other workshop repos, drop your own icon files in here and reference them from the module and README headers the same way the template does,  nothing else about the structure needs to change.
